## Hợp đồng M1 cần giữ xuyên các task

Mọi model request/response dùng `extra="forbid"`. Public JSON không chứa
đường dẫn filesystem. UUID dùng chuỗi JSON, số frame strict int. Timestamp audit
UTC ISO. `schema_version=1` cho contracts M1, không tái sử dụng version V1 jobs.

```python
# backend/app/annotation/contracts.py
from typing import Literal
from uuid import UUID
from pydantic import BaseModel, ConfigDict, Field, StrictInt

class Dto(BaseModel):
    model_config = ConfigDict(extra="forbid")

class Point(Dto):
    x: float = Field(ge=0, le=1, allow_inf_nan=False)
    y: float = Field(ge=0, le=1, allow_inf_nan=False)

class RegisterClip(Dto):
    operation_id: UUID
    source_job_id: UUID

class RoiWrite(Dto):
    operation_id: UUID
    expected_clip_revision: StrictInt = Field(ge=0)
    camera_setup_id: UUID
    polygon: list[Point] = Field(min_length=3, max_length=64)
    template_revision_id: UUID | None = None

class MediaView(Dto):
    frame_count: StrictInt = Field(gt=0)
    fps_num: StrictInt = Field(gt=0)
    fps_den: StrictInt = Field(gt=0)
    width: StrictInt = Field(gt=0)
    height: StrictInt = Field(gt=0)
    sample_aspect_ratio: str

class RoiView(Dto):
    id: UUID
    revision: StrictInt
    camera_setup_id: UUID
    polygon: list[Point]
    template_revision_id: UUID | None

class ClipView(Dto):
    schema_version: Literal[1] = 1
    id: UUID
    source_job_id: UUID
    original_name: str
    revision: StrictInt
    preparation_state: Literal["preparing", "ready", "failed", "releasing", "released"]
    source_state: Literal["available", "missing", "hash_mismatch"]
    failure_code: str | None
    source_sha256: str | None
    media: MediaView | None
    roi: RoiView | None
    preview_url: str | None
    prepared_bytes: StrictInt | None
```

`CameraSetupCreate(operation_id: UUID, name: str)` với name strip, 1–80 ký tự,
không rỗng. `CameraSetupView(id: UUID, name: str, revision: int,
template: RoiView | None)`. `TemplateWrite(operation_id: UUID,
expected_setup_revision: int, polygon: list[Point])` dùng cùng polygon validator.
`RetryPreparation(operation_id: UUID, expected_clip_revision: int)`;
`ReleasePreparedMedia(operation_id: UUID, expected_clip_revision: int)`;
`StorageView(used_bytes: int, limit_bytes: int, free_bytes: int)`;
`ErrorView(detail: str)` giữ lỗi ngắn không có stderr/private path.
List trả `{items: list[...], next_cursor: str|null}`, limit default 50, max 100;
cursor là opaque keyset theo created_at và id, invalid cursor trả 422.

Lần chuẩn bị đầu chưa xong có media/source_sha256 null; không fabricate frame
count. Sau release/reprepare, giữ metadata/hash đã xác minh trước, không xóa
chúng về null; preview_url chỉ khác null khi ready và source available.
prepared_bytes=0 sau thu hồi thành công, null khi chưa đo được; releasing phải
báo bytes còn chiếm chỗ thực tế, không giảm quota ngay lúc nhận lệnh.
ROI chỉ lưu khi source available và clip ready. Metadata phục vụ chia train/test
là M3 migration, chưa hiện form provenance trong M1.

```python
import hashlib
import io
from PIL import Image
from app.annotation.media import prepare_clip

def test_exact_frames_survive_random_seek(tmp_path, make_numbered_source,
                                         decode_source_rgb, frame_store):
    source = make_numbered_source(tmp_path / "source.mp4", frames=80, sar="2:1")
    before = hashlib.sha256(source.read_bytes()).hexdigest()
    prepared = prepare_clip(source, tmp_path / "staging", 25, 1, "2:1")
    reference = decode_source_rgb(source)
    clip_id = frame_store.publish_for_test(prepared, tmp_path / "staging")
    for index in [0, 79, 40, 39, 40, 1, 78]:
        actual = Image.open(io.BytesIO(frame_store.read_frame(clip_id, index))).convert("RGB")
        assert actual.tobytes() == reference[index]
    assert prepared.frame_count == 80
    assert hashlib.sha256(source.read_bytes()).hexdigest() == before
```

Matroska `-c:v ffv1 -level 3 -pix_fmt bgr0`; dùng raw RGB stdin, decode mỗi
chunk về rgb24 để kiểm byte hashes trùng nguồn trước publish. Chunk filenames
server-generated integer padded; manifest chứa start index/count/hash. Frame
request xác định chunk bằng start/count, decode từ đầu chunk đến local index
(không seek float), PNG encode không resize; LRU giữ bytes PNG tổng <=512 MiB.
Tối ưu decoder reuse khi liên tiếp trong cùng chunk nếu cần đạt gate, không
thay frame content để đổi tốc độ. Đây là derived index private, không video
training; source MP4 được giữ nguyên.

```python
# Logic xác định index, dùng manifest đã validate (không path từ request).
chunk = manifest.chunk_containing(index)
offset = index - chunk.start_frame
rgb = decode_chunk_rgb_at(chunk.resolved_path, offset)
if hashlib.sha256(rgb).hexdigest() != manifest.frame_sha256[index]:
    raise FrameIntegrityError("frame_hash_mismatch")
return encode_png(rgb, manifest.width, manifest.height)
```
